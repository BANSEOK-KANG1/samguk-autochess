# 필살기 원화·전체화면 컷인 v22 전달서

## 변경 목표

v22는 작은 초상화 아틀라스를 전체화면까지 확대해 보이던 흐릿함을 없애고, 필살기마다 장수와 전장이 하나의 장면처럼 보이도록 구성한 버전입니다.

- 조조, 관우, 주유 전용 16:9 필살기 키아트를 추가했습니다.
- 장수의 얼굴, 갑주, 무구는 기존 3D 디자인 방향을 유지했습니다.
- 아군과 적군의 발동 방향에 맞춰 원화와 정보 영역이 자동으로 반전됩니다.
- 전용 원화가 없는 장수는 현재 전장 이미지와 기존 초상화·전신 아틀라스를 조합하는 방식으로 동작합니다.
- 전체화면, 16:9, 울트라와이드, 낮은 높이의 브라우저에서도 컷인과 전투 로그가 서로 밀어내지 않도록 크기를 다시 계산합니다.

## 컷인 안전 영역

전용 원화는 장수를 왼쪽 약 35%에 두고 오른쪽을 정보 영역으로 비웠습니다.

- 아군 필살기: 장수는 왼쪽, 장수명·필살기명은 오른쪽
- 적군 필살기: 원화를 좌우 반전하고 장수명·필살기명은 왼쪽
- 문구 영역: 화면 가장자리에서 최소 3~6% 안쪽
- 컷인 높이: 전장 컨테이너 높이와 너비를 함께 계산해 최대 16:9 비율에 가깝게 유지
- 낮은 화면: 설명 문구를 먼저 숨기고 장수명과 필살기명은 유지
- 좁은 화면: 전투 로그를 숨겨 전장과 필살기 원화가 눌리지 않도록 처리

## 전체화면 깨짐 방지

- `100dvh`를 사용해 브라우저 상단·하단 UI 변화가 있어도 전투창 높이가 화면 밖으로 넘어가지 않습니다.
- 전투창은 고정 높이가 아니라 사용 가능한 화면 안에서 너비와 높이를 모두 100% 사용합니다.
- 컷인 원화는 독립된 합성 레이어에서 `transform`과 `opacity`만 애니메이션합니다.
- 원화 확대 중 전장 전체에 `filter`를 걸지 않아 이전의 깜빡임 가능성을 줄였습니다.
- 장수 정보와 원화는 서로 다른 레이어이므로 적군 원화만 반전되고 글자는 뒤집히지 않습니다.

## 신규 장수 원화 추가 규칙

1. 16:9 가로형으로 제작합니다.
2. 장수의 얼굴과 주무기가 모두 보이도록 왼쪽 35%에 배치합니다.
3. 오른쪽 40%에는 글자가 올라갈 수 있도록 고대비 디테일을 줄입니다.
4. 이미지 안에 글자, 한자, UI, 로고, 워터마크를 넣지 않습니다.
5. `app/hero-ultimate-art.ts`에 장수 ID와 웹용 원화 경로를 추가합니다.

## 생성 프롬프트 공통 규격

- 용도: 게임 전체화면 필살기 시네마틱 키아트
- 스타일: AAA급 동아시아 역사 판타지, 사실적인 3D 페인터리 렌더
- 구도: 16:9, 장수 왼쪽 35%, 오른쪽 UI 안전 영역
- 유지: 기존 얼굴, 갑주, 무구, 세력별 색상과 실루엣
- 제외: 글자, 한자, UI, 로고, 워터마크, 중복 인물, 잘린 얼굴과 주무기

생성은 내장 이미지 생성 방식으로 진행했고, 웹 배포본만 손실 압축 WebP로 변환했습니다.
