# 전투 모션 시스템 v21 전달서

## 목표

v21은 기존에 겹쳐 있던 전신 이미지, 구형 미니어처, 분절 관절 모션 규칙을 하나의 우선순위가 명확한 전투 모션 계층으로 통합한 버전입니다.

핵심 체감은 다음과 같습니다.

- 장수의 하체, 몸통, 머리, 비무장 팔, 무장 팔을 각각 분리해 움직입니다.
- 공격은 예비동작 → 타격 → 반동 → 복귀의 4단계로 구성됩니다.
- 필살기가 발동하면 일반 전투 진행을 잠시 유지한 채 초상화 컷인이 재생됩니다.
- 1성, 2성, 3성은 오라뿐 아니라 전장에서 실제 체격도 달라집니다.
- 전장 전체에 필터를 반복 적용하지 않고 합성 레이어와 투명도만 사용해 깜빡임을 줄였습니다.

## 관절 구조

현재 웹 프로토타입은 2.5D 분절 리그입니다. 하나의 장수 전신 이미지를 아래 다섯 영역으로 나누고 서로 다른 회전축을 적용합니다.

1. `segment-legs`: 골반과 무게중심, 달리기와 버티기
2. `segment-torso`: 호흡, 상체 비틀림, 공격 체중 이동
3. `segment-head`: 시선 고정, 공격 방향 추적
4. `segment-arm-back`: 균형 팔, 활시위 당기기, 보조 무기
5. `segment-arm-weapon`: 주무기 휘두르기, 찌르기, 주문 시전

각 분절은 경계가 벌어질 때 몸이 끊겨 보이지 않도록 낮은 불투명도의 전신 실루엣을 아래에 한 겹 유지합니다.

## 무기별 동작 문법

| 무기 | 일반 공격 | 필살기 |
| --- | --- | --- |
| 지휘검 | 짧은 예비동작 후 사선 베기 | 깃발을 세우고 크게 전진 베기 |
| 쌍검·쌍단검 | 양팔이 엇갈리는 2연속 교차 베기 | 잔상과 함께 앞뒤 팔이 연속 타격 |
| 언월도·방천화극·대도 | 긴 준비 후 몸통 전체 회전 베기 | 무장 팔의 회전 반경과 후속 반동 확대 |
| 기병창·사모 | 수평에 가까운 직선 찌르기 | 상체와 팔이 함께 긴 거리로 돌진 |
| 강궁 | 무장 팔 고정, 반대 팔로 시위 당김 | 조준 유지 후 큰 반동과 투사체 타격 |
| 군사 부채·지팡이 | 양팔을 열어 기를 모은 뒤 방출 | 상체 상승, 양팔 전개, 인장과 광원 폭발 |
| 철갑방패 | 낮은 중심에서 짧게 밀어붙임 | 방패 팔과 몸통을 함께 전진시켜 충돌 |

## 필살기 시네마틱

기본 속도에서는 약 1.22초, 2배속에서는 약 0.62초 동안 재생됩니다.

1. 전장 주변부가 어두워지며 다른 장수의 불투명도가 낮아집니다.
2. 시전자 진영 방향에서 고해상도 얼굴 초상화가 진입합니다.
3. 장수 이름, 전용 무기, 역할, 필살기명이 순차적으로 노출됩니다.
4. 장수별 한자 인장과 전신 잔상이 확대됩니다.
5. 광선 두 줄이 교차하는 타격 프레임에 실제 전장 기술 모션이 맞춰집니다.
6. 컷인이 빠져나가고 자동전투가 다음 행동 주기로 이어집니다.

아군과 적군은 초상화와 문구의 진입 방향이 반대로 구성되어 발동 주체를 즉시 구분할 수 있습니다.

## 성급별 체급

성급 배율은 전장 깊이에 따른 원근 배율과 결합됩니다.

| 성급 | 체격 배율 | 연출 |
| --- | ---: | --- |
| 1성 | 0.80 | 작은 실전 병력 체급, 기본 황동 별 |
| 2성 | 0.93 | 1성 대비 약 16% 확대, 은청색 후광과 승급진 |
| 3성 | 1.07 | 1성 대비 약 34% 확대, 금색 이중 후광·입자·강화 승급진 |

3성도 칸의 판독성을 해치지 않는 범위에서만 커지며, 이름표와 체력바 크기는 고정해 정보 배치를 안정적으로 유지합니다.

## 깜빡임 방지 원칙

- 필살기 중 전장 전체의 `filter`와 확대·축소를 반복하지 않습니다.
- 컷인은 독립된 합성 레이어에서 움직입니다.
- 배경과 전장 지물은 다시 렌더링하지 않고 그대로 유지합니다.
- 시네마틱 중 다른 장수는 필터가 아니라 `opacity`만 조절합니다.
- 전투 위치 이동과 관절 애니메이션은 서로 다른 요소가 담당합니다.

## 실제 3D 모델로 이전할 때

현재 웹 리그의 다섯 분절은 실제 3D 제작 시 다음 본 구조에 대응합니다.

- `segment-legs` → Root, Pelvis, Thigh, Calf
- `segment-torso` → Spine, Chest
- `segment-head` → Neck, Head
- `segment-arm-back` → Shoulder_L, Arm_L, Forearm_L
- `segment-arm-weapon` → Shoulder_R, Arm_R, Forearm_R, WeaponSocket

GLB 모델로 교체할 때에도 현재의 공격 4단계와 필살기 컷인 타이밍을 그대로 애니메이션 이벤트에 매핑할 수 있습니다.
