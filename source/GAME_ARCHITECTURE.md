# 삼국지 군단전 로컬 엔진 구조

## 핵심 게임 루프

1. 턴 시작: 여섯 전장 중 하나가 결정되고 7×4 지형 지물이 공개됩니다.
2. 적진 정찰: 상대 장수, 병과 구성, 병력, 진형, 전술이 실제 전투와 동일한 정보로 먼저 공개됩니다.
3. 장수 고용: 100명의 장수 풀에서 턴과 코스트에 맞는 후보 4명이 제시됩니다.
4. 턴당 1회 고용: 금화를 지불해 장수 한 명만 고용할 수 있습니다.
5. 지휘관 배속: 장수는 독립 유닛이 아니라 자신이 지휘할 수 있는 병과의 부대에만 배속됩니다.
6. 병과 편제: 배속된 장수의 지휘 가능 범위 안에서 보병·창병·기병·궁병·방패병·수군 편제를 변경합니다.
7. 대응 작전: 적 진형을 상대로 유리한 진형과 전술을 고르고 7×4 전장에 부대를 배치합니다.
8. 병력 자동전투: 병력 수, 사기, 병종 상성, 지형, 진형 카운터, 전술, 장수 지휘 효과가 행동 주기마다 계산됩니다.
9. 전투 정산: 생존 병력과 숙련도가 다음 턴으로 이어지고 새로운 상대 정찰과 장수패가 갱신됩니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

브라우저에서 개발 서버 주소를 열면 됩니다. 진행 상태는 브라우저 로컬 저장소에 자동 저장되며 외부 데이터베이스가 필요하지 않습니다.

검증은 다음 명령으로 실행합니다.

```bash
npm run lint
npm test
```

## 엔진 모듈

- `app/army-data.ts`
  - 6병종 기본 능력치와 상성
  - 14개 지형 지물의 공격·방어·사거리·기동 보정
  - 6개 진법과 4개 전술
  - 진법 간 카운터 관계와 진형 셀
  - 100명 장수 풀의 코스트 기반 고용패 생성
  - 장수 역할·코스트·세력을 지휘 가능 병과와 부대 효과로 변환
- `app/army-engine.ts`
  - 결정론적 난수 시드
  - 전투 전 정찰과 실제 전투가 공유하는 적군 편성 생성
  - 병력 이동과 목표 탐색
  - 병종 상성, 지형, 진법 카운터, 전술, 지휘관 보정
  - 사상자와 사기 붕괴
  - 지휘관 기술 발동
  - 승패와 잔존 병력 정산
- `app/army-stage.tsx`
  - 7×8 교전 공간에서 양측 7×4 진영을 표현
  - 한 부대를 다수 병사 대형으로 시각화
  - 병력·사기·장수 기술·패주를 실시간 표시
- `app/page.tsx`
  - 상대 진형 정찰과 대응 진형 추천
  - 장수 고용패, 지휘 가능 병과 검증, 병과 개편
  - 지휘관 배속, 지형 배치, 진법·전술 선택
  - 턴 진행과 로컬 자동 저장

## 확장 원칙

현재 엔진은 UI와 분리된 순수 상태 전이 방식입니다. 같은 초기 상태와 시드를 입력하면 같은 전투 결과가 나오므로 리플레이, 서버 검증, 비동기 대전으로 확장할 수 있습니다.

대전 모드에서는 클라이언트가 선택한 `부대 편성 + 장수 배속 + 28칸 배치 + 진법 + 전술`만 서버에 전송하고, 서버가 동일한 엔진으로 결과를 재계산하는 구조가 적합합니다.
